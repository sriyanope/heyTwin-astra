# heyTwin

heyTwin takes a photo of one piece of clothing you already own and shows you complete outfits you could actually wear it in.

Built for a GPT Astra hackathon by a two-person team in a 5-hour build window.

No application code exists in this repository yet — it currently contains only the planning/instructions pack.

For full product scope, see [`instructions/PRODUCT_BRIEF.md`](instructions/PRODUCT_BRIEF.md).
For the docs-pack overview (problem, essential flow, features, docs index), see [`instructions/README.md`](instructions/README.md).
